# Note Taking App Features
> Features of tools like Notion, Obsidian, Evernote, OneNote, Bear, and Roam Research — covering everything from quick capture to a full second brain.

---

## 1. Note Creation & Editing

The core writing experience.

- Create notes instantly with a single click or keyboard shortcut
- Rich text editor with WYSIWYG formatting
- Markdown support (full and inline)
- Headings: H1, H2, H3, H4, H5, H6
- Bold, italic, underline, strikethrough, inline code
- Highlight text with color
- Blockquotes and callout blocks
- Horizontal dividers / separators
- Superscript and subscript text
- Word count and character count
- Reading time estimate
- Focus / distraction-free writing mode
- Typewriter mode (keeps cursor centered)
- Auto-save while typing
- Version history — restore any previous state of a note
- Duplicate note
- Note templates for recurring structures
- Drag-and-drop block reordering
- Collapsible / toggle blocks for long content
- Undo / redo with deep history

---

## 2. Organization & Structure

Keep notes findable and logically grouped.

- Notebooks / folders for grouping notes
- Sub-notebooks / nested folders (unlimited depth)
- Stacks of notebooks (folder groups)
- Tags — add multiple tags per note
- Nested tags (parent / child tag hierarchy)
- Favorites / starred notes for quick access
- Pin notes to top of a list
- Color-coded notebooks and notes
- Custom sort order: by date, title, or manual drag
- Archive notes without deleting
- Trash / deleted notes recovery
- Recently viewed notes history
- Note count per folder and tag
- Home / dashboard view with pinned content
- Inbox — default capture destination for quick notes

---

## 3. Linking & Knowledge Graph

Connect ideas and build a networked knowledge base.

- Internal note links — link any note to another
- Backlinks — see all notes that link to the current one
- Unlinked mention detection — suggest links you haven't made yet
- Bi-directional linking
- `[[Wiki-style]]` double bracket linking
- Block-level references — link to a specific paragraph, not just a note
- Graph view — visual map of all connected notes
- Local graph — connections only for the current note
- Alias links — link to a note under a different display name
- Orphan note detection — find unlinked / isolated notes
- Daily notes linked automatically by date
- MOC (Map of Content) pages for topic hubs

---

## 4. Rich Media & Embeds

Go beyond plain text.

- Image upload and inline display
- Image resizing and alignment (left, center, right)
- Image caption support
- PDF attachment and inline PDF viewer
- Audio file attachment and inline playback
- Video file attachment and inline playback
- Embed YouTube, Vimeo, and other video URLs
- Embed web pages via iframe
- Embed tweets, Google Maps, Figma frames, etc.
- File attachments of any type (ZIP, DOCX, XLSX, etc.)
- Drawing / sketch canvas (freehand ink)
- Handwriting recognition from stylus input
- Whiteboard / infinite canvas mode
- Mermaid diagram rendering (flowcharts, sequence diagrams)
- LaTeX / math equation rendering (KaTeX or MathJax)
- Code blocks with syntax highlighting (50+ languages)
- Runnable code blocks (in some tools)

---

## 5. Tables & Databases

Structured data inside notes.

- Simple markdown-style tables
- Advanced table editor with row/column insertion and deletion
- Column resizing and alignment
- Formula support in table cells
- Database / spreadsheet view (Notion-style)
- Multiple views for the same database: table, board, calendar, gallery, list, timeline
- Database properties: text, number, date, checkbox, select, multi-select, URL, email, phone
- Filter rows by any property
- Sort rows by any property
- Group rows by property value
- Rollup and relation properties between databases
- Formula columns with calculated values
- Database templates for new entries
- Linked database views — show the same data in multiple places

---

## 6. Tasks & To-Dos

Lightweight task management inside notes.

- Checkbox / to-do items inside any note
- Nested checklists (sub-tasks under tasks)
- Due date on individual tasks
- Recurring task support
- Priority levels on tasks
- Task status: to-do, in progress, done, cancelled
- Dedicated tasks / to-do view across all notes
- Filter tasks by status, due date, priority
- Reminders and notifications for due tasks
- Kanban board view for tasks
- Calendar view for tasks with due dates
- Today view — tasks due today across all notes
- Progress bar on checklists
- Convert any line into a task with a shortcut

---

## 7. Search & Discovery

Find anything instantly.

- Full-text search across all notes and attachments
- Search within a specific notebook or tag
- Search by title only mode
- Boolean search operators (AND, OR, NOT)
- Search by date range (created or modified)
- Search by media type (notes with images, PDFs, etc.)
- Saved searches / search shortcuts
- Recent searches history
- Fuzzy / typo-tolerant search
- Search inside PDFs and attached documents
- AI-powered semantic search (find by meaning, not just keywords)
- Quick open / command palette (Cmd+K style)
- Filter search results by tag, notebook, or date

---

## 8. Daily Notes & Journaling

Capture thoughts tied to time.

- Auto-created daily note for today's date
- Navigate between days with previous / next buttons
- Weekly, monthly, and yearly note templates
- Habit tracker integrated into daily notes
- Mood and energy logging
- Reflection prompts and journaling templates
- Calendar view to navigate to any day's note
- Streak tracking for daily writing consistency
- Time-stamped entries / log mode within a note
- Word count goals per day / session
- Morning pages and evening review templates

---

## 9. Code & Technical Notes

Built for developers and technical writers.

- Code blocks with syntax highlighting (Python, JS, SQL, Bash, etc.)
- Inline code formatting
- Line numbers in code blocks
- Copy code button on code blocks
- Diff / change highlighting in code blocks
- Terminal / shell command blocks
- API documentation templates
- Sequence diagrams via Mermaid
- ERD (entity relationship diagram) support
- LaTeX math rendering for formulas and equations
- Table of contents auto-generated from headings
- Footnotes and endnotes
- Citation and bibliography support
- Technical writing templates (RFC, spec, ADR, PRD)
- Export to Markdown, HTML, PDF, or DOCX

---

## 10. Capture & Quick Input

Get ideas in fast, from anywhere.

- Web clipper browser extension — clip full pages, articles, or selections
- Clip as simplified article, screenshot, or full HTML
- Highlight and annotate clipped web content
- Email to note — forward emails into your notes
- Mobile share sheet integration — share from any app to notes
- Quick capture widget on home screen (mobile)
- Voice memo recording and transcription
- Camera capture — photograph documents, whiteboards, receipts
- OCR on images — extract text from photos
- Scan documents and auto-crop / flatten
- SMS / messaging bot for quick note capture
- Apple Watch / wearable quick capture
- Siri / Google Assistant / voice assistant integration
- Drag-and-drop from browser or file manager

---

## 11. Views & Navigation

Different ways to see and browse your notes.

- List view — compact note list with preview snippet
- Card / grid view — visual tile layout
- Calendar view — browse notes by date created or modified
- Map view — notes pinned to geographic locations
- Graph / network view — visual knowledge map
- Outline view — hierarchical document structure
- Table of contents sidebar for long notes
- Split-pane editing — two notes side by side
- Breadcrumb navigation for nested folders
- Back and forward navigation (browser-style)
- Recently edited notes panel
- Note preview on hover
- Fullscreen single-note mode
- Presentation / slideshow mode from a note

---

## 12. Templates

Speed up repetitive note structures.

- Built-in template library (meeting notes, project brief, daily log, etc.)
- Custom template creation from any note
- Template variables (auto-fill date, title, author, etc.)
- Template gallery — community and official templates
- One-click template insertion
- Default template per notebook or note type
- Template categories and search
- Recurring note templates on a schedule
- Import templates from other users

---

## 13. AI & Smart Features

Intelligent assistance built into the editor.

- AI writing assistant — continue, summarize, or rewrite selected text
- AI-generated note summary
- Auto-tagging suggestions based on content
- Smart search — find notes by meaning, not just keywords
- AI chat over your notes — ask questions about your knowledge base
- Transcription of audio and video recordings
- OCR on images and scanned documents
- Auto-link suggestions — detect unlinked mentions
- AI-generated action items from meeting notes
- Sentiment analysis on journal entries
- Grammar and spell check
- Style and clarity suggestions
- Auto-formatting (detect and apply heading levels)
- AI-powered flashcard generation from notes
- Language translation of note content

---

## 14. Export & Import

Take your data anywhere.

- Export individual notes as Markdown, PDF, HTML, DOCX, or plain text
- Export entire notebook as a ZIP of Markdown files
- Export with attachments bundled
- PDF export with custom styling and cover page
- Import from Evernote (ENEX format)
- Import from Notion, Roam Research, Bear, OneNote
- Import plain Markdown files and folders
- Import from CSV into database views
- Publish note as a public web page
- Share read-only link to a note
- Embed note on external website via iframe
- Print note with clean formatting

## 15. Settings & Customization

Make the tool your own.

- Dark mode, light mode, and system-adaptive theme
- Custom accent / highlight colors
- Font family selection (serif, sans-serif, monospace)
- Font size and line spacing adjustments
- Editor width: narrow, medium, full width
- Custom CSS injection (advanced theming)
- Plugin / extension system (Obsidian community plugins, etc.)
- Hotkey / keyboard shortcut customization
- Language and locale settings
- Spell check language selection
- Auto-correct and text expansion / snippets
- Default note location on capture
- Sidebar layout and panel customization
- Note list sort preference

---

## 16. Sync & Backup

Keep notes safe and available everywhere.

- Real-time sync across all devices (desktop, mobile, web)
- Offline access — read and edit without internet
- Conflict resolution on simultaneous edits
- End-to-end encryption option
- Local vault / local-first storage (Obsidian model)
- Cloud backup with point-in-time restore
- Version history per note (hourly, daily snapshots)
- Manual backup export to local storage
- iCloud, Dropbox, OneDrive sync support
- Git-based sync for plain Markdown vaults
- Multi-device session management

*Note taking tools covered: Notion, Obsidian, Evernote, Microsoft OneNote, Apple Notes, Bear, Roam Research, Logseq, Craft, Joplin, and Standard Notes. Feature availability varies by platform and subscription tier.*
